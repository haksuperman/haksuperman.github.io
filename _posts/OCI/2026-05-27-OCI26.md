# 2. StorageClass

## 2.1. StorageClass 정의 파일(YAML) 작성
- 기본으로 구성되어 있는 oci-bv는 paravirtualized 타입으로 지정되지 않음 → iSCSI 타입으로 Attach
- paravirtualized 타입이 명시된 신규 StorageClass 생성 필요

```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: oci-bv-paravirtualized
provisioner: blockvolume.csi.oraclecloud.com
parameters:
  attachment-type: "paravirtualized"
reclaimPolicy: Delete
volumeBindingMode: WaitForFirstConsumer
allowVolumeExpansion: true
```
![image](/assets/img/posts/OCI/OCI26_01.png)


## 2.2. StorageClass 생성 및 상태 확인

```bash
# StorageClass 생성
kubectl apply -f storageclass-paravirtualized.yaml

# PVC 상태 확인
kubectl get sc
```

# 3. PVC(Persistent Volume Claim)
## 3.1. PVC 정의 파일(YAML) 작성
1. 사용할 볼륨의 크기와 특성 정의
2. 파일명 : \<적절한 이름 입력\>  
   (여기서는 csi-bv-pvc.yaml)

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: mynginxclaim
spec:
  storageClassName: "oci-bv-paravirtualized"
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 50Gi
```
![image](/assets/img/posts/OCI/OCI26_03.png)

## 3.2. PVC 생성 및 상태 확인

```bash
# PVC 생성
kubectl apply -f csi-bv-pvc.yaml

# PVC 상태 확인
kubectl get pvc
```
![image](/assets/img/posts/OCI/OCI26_04.png)

> 아래와 같이 Pending 상태이다. 이는 oci-bv StorageClass 정의에 `volumeBindingMode: WaitForFirstConsumer`가 포함되어 있기 때문이다.
>
> 해당 설정은 **이 PVC를 실제로 사용하는 파드(Pod)가 생성될 때까지 실제 볼륨 생성을 대기**한다.
>
> ```bash
> [k8s-admin@oke-bastion persistentvolume-paravirtualized]$ kubectl get pvc
> NAME           STATUS    VOLUME   CAPACITY   ACCESS MODES   STORAGECLASS             VOLUMEATTRIBUTESCLASS   AGE
> mynginxclaim   Pending                                      oci-bv-paravirtualized   \<unset\>                 20s
> ```

# 4. Pod
## 4.1. 정의 파일(YAML) 작성
1. 생성한 PVC를 마운트하여 사용할 파드 생성
2. 파일명 : \<적절한 이름 입력\>  
   (여기서는 nginx-pod.yaml)

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx
spec:
  containers:
    - name: nginx
      image: docker.io/library/nginx:latest
      ports:
        - name: http
          containerPort: 80
      volumeMounts:
        - name: data
          mountPath: /usr/share/nginx/html # 컨테이너 내부의 마운트 경로
  volumes:
    - name: data
      persistentVolumeClaim:
        claimName: mynginxclaim # 3.1.에서 생성한 PVC 이름
```
![image](/assets/img/posts/OCI/OCI26_07.png)

## 4.2. 파드 생성 및 확인

```bash
# 파드 생성
kubectl apply -f ./nginx-pod.yaml

# 파드 생성 확인
kubectl get pods
```

![image](/assets/img/posts/OCI/OCI26_08.png)
